v0.1.5：恢复原生播放页深色模式，清晰文字、评论全部展开及 BewlyCat 动态页布局。

- 补全原生视频信息、简介、合集和评论 Shadow DOM 的深浅色变量；支持强制明暗及跟随系统。不移动原生播放器节点或修改视频绘制层。
- 系统无衬线字体统一正文及信息文字，默认正文 15px / 500 字重，主要信息文字 14px；取消相关文字的等宽回退与强制灰度平滑。字号、字重、行高、强调色、圆角、实色面板和减少动效均可配置。
- 评论楼层增加「全部展开楼层」「收起楼层」及继续展开。通过原生分页方法顺序加载，每次默认最多 5 页，可配置 1–10 页；已加载页合树、去重并保留点赞状态，失败可重试。缩进、线宽、连线显示也可设置。
- 动态首页改为 BewlyCat Moments 布局：单/双列卡片、UP 主头像条、可选个人资料/直播/热搜侧栏、特别关注及置顶 UP 主。适配窄屏，保留视频、图片、番剧附件、富文本和转发原文。
- 动态页支持类型、关键词及 UP 主过滤，手动/自动分页，当前/新标签打开，紧凑卡片与标签居中。卡片菜单可直接特别关注、置顶或屏蔽。
- 设置新增搜索，各项改动实时保存，旧设置自动补全新字段，现有导入导出继续兼容。

这是 BewlyCat 动态布局与所列功能的适配版，尚未移植其全部功能。
