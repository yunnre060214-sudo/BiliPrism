首个 Chrome / Edge 本地使用版，未提交浏览器扩展商店。

下载 **BiliPrism-v0.1.0-chromium.zip**，解压后在浏览器扩展管理页开启开发者模式，使用「加载已解压的扩展程序」，选择包含 manifest.json 的目录。无需安装 Node.js 或 Tampermonkey。

- MARGIN 风格首页与页面适配，普通高斯模糊、静态渐变背景。
- 推荐过滤、收藏、稍后再看、足迹与命令面板。
- 全屏滚轮调音、速度记忆、宽屏布局。
- 播放页字幕导出，支持 SRT / TXT / JSON 与语言选择。
- 默认关闭天气、开场动画和封面自动预览。

这是融合工程的第一版，尚未完整迁入 BewlyCat 和个人 Userscripts。评论导出、直播和其他个人脚本功能不在本次范围内。请停用其他同时接管 B 站页面的扩展与重复脚本。

验证：TypeScript 检查、逻辑测试，以及离线接口夹具下的真实扩展加载与功能测试。线上账号、地区限制及页面变化需要本地使用反馈。更新时覆盖原目录并重新加载扩展。
